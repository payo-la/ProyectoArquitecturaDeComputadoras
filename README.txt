# Proyecto final — Arquitectura de Computadoras

Sitio estático listo para publicarse con GitHub Pages.

## Archivos
- `index.html`: estructura y contenido de la página.
- `style.css`: diseño adaptable a celular y computadora.
- `script.js`: filtros de documentos y menú móvil.
- `pdfs/`: carpeta donde debes colocar tus 9 archivos PDF.

## Importante: nombres de los PDF
Coloca los archivos dentro de `pdfs/` y usa exactamente estos nombres (respetando espacios, puntos y acentos):

1. `Reporte P.1.pdf`
2. `Reporte P.2.pdf`
3. `Reporte P.3.pdf`
4. `Reporte P.4.pdf`
5. `Tarea 1.pdf`
6. `Tarea 1 U3.pdf`
7. `Gamas de los eq de computo.pdf`
8. `Diseño de equipos.pdf`
9. `Cotizacion de equipos.pdf`

Si alguno de tus archivos tiene otro nombre, puedes renombrarlo o modificar el enlace correspondiente en `index.html`.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub, por ejemplo `ProyectoArquitecturaDeComputadoras`.
2. Descomprime este ZIP en tu computadora.
3. Sube al repositorio los archivos `index.html`, `style.css`, `script.js` y la carpeta `pdfs` completa.
4. En el repositorio abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/(root)`, y presiona **Save**.
7. Espera a que termine la publicación y abre la dirección que aparece en esa misma sección.

GitHub Pages publica el sitio desde archivos estáticos del repositorio. Recuerda que el sitio y los PDF serán accesibles públicamente; no subas información privada.
